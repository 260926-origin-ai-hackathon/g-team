## 承認画像との意図的な差

- 「8分前」「1分前」、時刻、いいね、写真枚数は実データから算出。画像中の過去12枚という数字は固定せず、デモでは素材のある6枚を表示する。
- 実機未接続を示す画面デモのラベルとシナリオ切替を追加。
- 歩行アイコンはBootstrap Iconsの標準素材。その他は既存Lucide。原画の手描き形状との完全一致は行っていない。
- APIの契約、送信・並べ替え・削除・設定保存処理は継続利用。
- 写真の原画像が提供されていないため、デモ写真は承認画像の写真領域を切り抜き表示。ライブ写真にはこの処理を適用しない。
