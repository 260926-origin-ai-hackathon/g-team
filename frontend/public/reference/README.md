# 承認済みUIのデモ素材

`home.png` と `gallery.png` は、ユーザー提供の `ui-approved-20260925 2/` 内の承認画像をそのままコピーしたものです。`PhotoImage.tsx` が写真の部分だけを表示します。画像内のUIはアプリとして使わず、画面・文字・操作はReact/CSSで実装しています。ライブ接続時はAPIの写真を表示します。デモ写真の高解像度原本は未提供です。
